# TSA HTML Scene Modularization and Assembly Protocol v1.0.0

This package defines how to decompose a film into independently testable HTML scene modules and assemble them with a Master HTML Engine.

The Video Breakdown Protocol remains available for Gemini or another environment when external source analysis is needed. It does not need to be rerun if an adequate, evidence-labeled breakdown already exists.

This is a proposed standalone protocol. It has not been merged into the user's existing production protocol or INDEX because those source files were not supplied in this turn.
