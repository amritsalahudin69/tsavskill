# TSA Video Project — Modular Breakdown Package

This package follows **TSA Video Breakdown Protocol v1.0.0**.

## Files
- `PROTOCOL.md` — reusable standard and workflow.
- `MASTER_GEMINI_VIDEO_ANALYSIS_PROMPT.md` — prompt for Gemini or another video-reading agent.
- `templates/` — reusable Markdown structures for each output module.

## Default decisions
- Fidelity: BOTH (source reconstruction + separate cinematic adaptation).
- Sources: BOTH animation and gameplay/game cinematics.
- Output: modular Markdown files.
- Final implementation: HTML/Three.js, subject to canonical asset capabilities.

## Important
The source reconstruction is evidence-based. The adaptation is a proposal. The HTML execution specification is an implementation handoff. Do not merge these layers.
